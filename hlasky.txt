# ============================================================
#  Mraq – všechny hlášky
# ============================================================
#  Tenhle soubor si appka sama načítá. Stačí ho přepsat,
#  pushnout do main a za minutu to Mraq říká po tvým.
#
#  Pravidla:
#   - jeden řádek = jedna hláška
#   - [nazev] = začátek skupiny (nálady). Názvy skupin neměň.
#   - řádky začínající # se ignorují (poznámky)
#   - prázdné řádky nevadí
#   - do hlášek můžeš dávat proměnné ve složených závorkách:
#       {teplota}   teplota teď, např. 14
#       {pocitove}  pocitová teplota
#       {vitr}      vítr v km/h
#       {narazy}    nárazy větru v km/h
#       {sance}     šance na déšť v %
#       {mm}        kolik napadne do konce dne (mm)
#       {vychod}    východ slunce, např. 7:12
#       {zapad}     západ slunce
#       {stav}      popis počasí malými písmeny, např. „polojasno“
#       {misto}     název místa, např. Praha
#
#  Mraq vybírá náladu podle počasí v čase, kam se zrovna díváš
#  (i když posouváš časovou osu). Při ťuknutí na Mraqa řekne
#  další hlášku z té samé skupiny.
# ============================================================
